# Troubleshooting Your Code Using IBM Bob

**Overview:**  
IBM Bob specializes in answering technical questions, explaining complex concepts, analyzing code, and providing expert guidance across multiple programming languages and frameworks. Let Bob handle the research and problem-solving so you can focus on building great software.

---

### Learning Outcomes
After completing this lab, you should be able to:
* Use **IBM Bob** in **Code mode** to analyze source code for syntax and functional errors.
* Write structured prompts to guide code troubleshooting and error classification.
* Review AI-generated recommendations and apply proposed fixes to existing code.
* Compare original and corrected code to understand how specific changes resolve errors.
